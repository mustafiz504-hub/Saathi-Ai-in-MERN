# Saathi-Ai Project: Detailed Progress Log & Knowledge Base

Bhai, ye lo ab tak ki saari details ekdum गहराई (deeply) me, taaki aapko har cheez samajh aa jaye:

---

### **1. 17 March 2026: Development Environment Setup (Docker)**
- **Kyu kiya?**: Kabhi-kabhi project ek computer me chalta hai par dusre me "dependencies" ki wajah se error dene lagta hai.
- **Kya kiya?**: Ek `Dockerfile` banaya jo ek setup generate karta hai. Iska matlab hai ki ab ye project kisi bhi computer pe exact same settings ke saath chalega (Node.js version, database setup, etc.).

### **2. 19 March 2026: User Profile & Security Fix**
- **Problem**: Jab hum users list fetch karte the, to do issues the:
    1. List me hamara khud ka naam bhi dikhta tha (jo chat me zaruri nahi hai).
    2. API response me users ke "password" bhi aa rahe the, jo security ke liye bahut khatarnak hai.
- **Solution**: `getUserProfile` controller me MongoDB query me changes kiye:
    - `.find({ _id: { $ne: currentUser } })`: Isse current user search se bahar ho gaya.
    - `.select("-password")`: Isse password wala field response me aana band ho gaya.
- **Fayda**: Ab sidebar clean hai aur hamara data secure hai.

### **3. 24 March 2026: Secure Routes Middleware (The Gatekeeper)**
- **Kyu?**: Kisi bhi API ko direct call karke messages read karna impossible banana tha.
- **Kaise?**: `secureRoute.js` naam ka ek middleware banaya.
- **Logic**: Jab bhi koi user messages ya profile request karta hai, ye middleware check karta hai ki user ke browser cookies me **JWT Token** hai ya nahi. Agar token valid nahi hai, to wo request aage nahi jane deta (Access Denied).

### **4. 27 March 2026: The "Big Fix" (Auth & API Integration)**
Ye ab tak ka sabse bada kaam tha. Humne client aur server ko ek dusre ke saath sync kiya:
- **API Path Mismatch**: Frontend `/api/user/` hit kar raha tha jabki Backend `/api/v1/user/` par respond kar raha tha. Humne dono ko ek path par set kiya.
- **Google vs. Normal Login**: Pehle Google login aur normal login dono alag tarike se interact kar rahe the. Humne unko unite kiya taaki backend dono ko ek hi "User" ki tarah treat kare.
- **Sidebar & Users Layout**: Sidebar me users isliye nahi dikh rahe the kyunki variables ke naam backend aur frontend me alag the (jaise `users` vs `allUsers`). Use hamne ek jaisa banaya.
- **Logout Logic**: Jab user logout pe click karega, to Browser se `cookie` clear hogi aur Local Storage se user details udd jayengi.

### **5. 28 March 2026: UI Updates & Polish**
- **Chat Background**: `Client/src/Home/right/Right.jsx` me ek stunning chat background image insert ki.
- **Logic**: Image ko import karke styling me `background-image` property ka use kiya, taaki chat interface visually attractive lage (jaise ChatGPT ya WhatsApp hota hai).

---

### **6. 29 March 2026: Messaging System & Model Integration**
Aaj humne **Saathi-Ai** ka core feature (Chating) implement kiya:
- **Database Models**: 
    - `message.model.js`: Isme har individual message (sender, receiver, content) store hoga.
    - `conversation.model.js`: Ye "participants" (kaun kisse baat kar raha hai) aur unke beech ke saare "messages" ki list rakhta hai.
- **Messaging Logic (Backend)**: 
    - `sendMessage`: Ye controller check karta hai ki participants ke beech pehle se conversation hai ya nahi. Agar nahi hai, to nayi banata hai aur message save karta hai.
    - `getMessages`: `.populate("messages")` ka use karke humne ensure kiya ki database se sirf IDs nahi balki pura message content (text, time) mil jaye.
- **Frontend Refinements**: 
    - `UseGetAllUsers`: Hook ko fix kiya taaki browser cookie automatically send ho aur user list bina kisi manual header ke fetch ho sake.
    - `Left.jsx`: Sidebar user list ko map kiya taaki har signed-up user wahan dikhe.
- **Documentation**: `message.txt` banaya taaki messaging flow aur models ka logic hamesha clear rahe.

### **Current Tech Stack Summary:**
1.  **Backend**: Node.js, Express, MongoDB (Database).
2.  **Frontend**: React.js, Tailwind CSS (Styling), Axios (API calls).
3.  **Auth**: HTTP-only JWT Cookies (Session Security) + Google OAuth.
4.  **Messaging**: Conversation-based schema with automatic message population.
